I care about more than just making things work. I focus on **architecture, maintainability, performance, user experience, API design, database modeling, and clean code**.

### 🔧 What I Work With

* **Frontend Architecture** — React-based applications with reusable component systems
* **Backend Architecture** — Laravel / NestJS modular applications and RESTful APIs
* **API Development** — Authentication, authorization, validation, error handling and documentation
* **Database Design** — Relational modeling, relationships, migrations and query optimization
* **State Management** — Redux, Zustand and server-state management with React Query
* **Caching** — Redis-based caching and performance strategies
* **Security** — Authentication, authorization, hashing, validation and common API security practices
* **Performance** — Code splitting, lazy loading, caching, bundle optimization and Core Web Vitals
* **Testing** — Automated tests and API/application-level validation
* **Desktop Development** — Tauri + React applications with Rust-backed native functionality
